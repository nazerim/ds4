## #785 — disconnect detection: NOT superseded (and why it looks superseded)

PR antirez/ds4#785 "fix: detect client disconnect on pure FIN; log cancelled jobs" — open,
base `b0a147a7`. Ships `ds4_server.c` + `tests/live_disconnect_test.py`.

- **MISTAKE #1 — the trap:** upstream tip *contains* `client_socket_disconnected`,
  `client_poll_revents_disconnected`, `client_recv_errno_disconnected` and the
  `"client disconnected"` log, which reads as "already merged". It is not: those names
  already existed **at the PR's own base** —
  `git grep -c client_socket_disconnected b0a147a7 -- ds4_server.c` → **6** hits — which is
  why the PR diff shows them as context/removed lines. Presence-in-tip proves nothing;
  presence-in-base-diff-context is the same fact.
- The **actual fix is absent upstream**: `MSG_PEEK` in `ds4_server.c` → **0 hits at
  `origin/main`** (`git grep -c MSG_PEEK origin/main -- ds4_server.c` exits 1 printing
  nothing — MISTAKE #2: empty `git grep -c` output on a no-match file means zero, *not* an
  error), vs **2 hits at fork HEAD** — that pair is the control proving the probe can
  report a positive. Tip `ds4_server.c:15232` still reads `if (rc == 0) return false;`.
- Linked upstream issue **#786** ("client disconnect mid-generation not detected on clean
  TCP FIN (Darwin poll bug)") — still open, **0 comments**; #785 is the only candidate patch.
- **Decision (recorded):** rebase onto `origin/main` + **exactly one ping, then stop** — no
  second ping regardless of response. Expected value is low (maintainer silence, below), so
  the rebase is preparation, not a message.
- **MISTAKE #3 — rebase verification recipe (this is the important correction):** checking a
  rebase with `git diff <old-head> <new-head>` and expecting **empty** is **inverted** —
  that compares *trees* across ~432 upstream commits (`b0a147a7..origin/main` = 432; the
  same span moves `ds4_server.c` +4222/−570), so it is empty only for a **broken** rebase
  that dropped upstream. Correct check:
  `git range-diff <base>...<old> origin/main...<new>` (expect all `=`) **plus** a
  `@@`-header-stripped comparison of `git diff base old` vs `git diff origin/main new`.
  Do not bare-`cmp` two diffs: `@@` line numbers *must* shift in a rebase.
- **Blocked on a window:** the PR ships `tests/live_disconnect_test.py`, which needs a
  locally built server → engine holds the process lock → engine-stopped window,
  coordinator-scheduled (see `AGENTS.md` Build & test).
- Branch plumbing: the fix commits live on the local mirror repo
  `/Users/naz/Projects/ds4-upstream`, branch `fix/disconnect-detection` (2 ahead:
  `45d7d56` fix, `9bd4c48` regression test, both 2026-08-12). **Caveat:** that mirror's own
  refs are stale (objects like `b3f5018` do not exist in it) — do *not* use it for upstream
  tip facts; use `origin/main` in the fork repo.
