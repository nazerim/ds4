`TOKFP` uses bit 5 of `ext_flags` without changing how cache keys are classified (`ds4_kvstore.c:185-189`, `ds4_kvstore.c:406`). The four existing flags are unchanged, and bit 4 is unused. On the pre-PR base, an otherwise compatible checkpoint can still restore its KV payload, but its on-disk tool map won't be replayed: the old reader expects the tool-map header where the stamp now sits, and skipping the tool map doesn't undo the KV restore.
